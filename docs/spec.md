# 概要

ブラウザの Notification API と連携し、設定した時間を1件だけカウントダウンするレトロLED風タイマーです。
タイマー名と分・秒を入力でき、終了時には画面内の完了表示とデスクトップ通知で知らせます。

# 機能仕様

- 扱うタイマーは同時に1件です。
- 初期値は `3分00秒`（`03:00`）です。ページを再読み込みすると初期状態に戻ります。
- 時間は次の範囲で直接入力できます。
  - 分: `0〜99分`
  - 秒: `0〜59秒`
  - 範囲外の値は入力時に上限・下限へ丸めます。
  - 入力欄と残り時間は2桁の `MM:SS` 形式で表示します。
- タイマー名は任意入力で、最大50文字です。
- タイマーの状態は `idle`（READY）、`running`（RUNNING）、`paused`（PAUSED）の3種類です。
- 状態ごとの操作と遷移は次のとおりです。
  - `idle`: Startを表示します。タイマー名と時間を編集できます。
  - `idle → running`: Startを押し、通知が利用可能かつ許可済みになった場合に開始します。
  - `running → paused`: Pauseを押すと、その時点の残り時間で一時停止します。
  - `paused → running`: Resumeを押すと、保持している残り時間から再開します。
  - `running / paused → idle`: Resetを押すと、開始時に確定した設定時間へ戻ります。設定時間とタイマー名は保持し、メッセージは消去します。
  - `running → idle`: 残り時間が0になると完了処理を行い、表示を設定時間へ戻します。
- `running` と `paused` の間は、タイマー名および分・秒入力を無効化します。
- `00:00` でStartを押した場合は開始せず、`1秒以上を設定してください` と表示します。
- カウントダウンは250ミリ秒間隔で更新処理を行い、単純な1秒減算ではなく、`Date.now()` と終了予定時刻の差から残り秒数を再計算します。
- 完了時には次の処理を行います。
  - ブラウザ通知を1件作成します。
  - タイマー名が入力されている場合、通知タイトルはその名前です。
  - タイマー名が空の場合、通知タイトルは `タイマー終了` です。
  - 通知本文は `設定した時間になりました` です。
  - 画面には `Time up!` を表示します。
  - 次回Start時に完了メッセージを消去します。
- 通知権限はStart操作の中でのみ確認・要求します。
  - Notification APIに非対応の場合は開始せず、`このブラウザでは通知を利用できません` と表示します。
  - 権限が `granted` の場合はそのまま開始します。
  - 権限が未決定の場合は `Notification.requestPermission()` を呼び、許可された場合だけ開始します。
  - 権限が `denied` の場合は再要求せず、ブラウザ設定からの許可を案内します。
  - 権限要求が拒否された場合や確認に失敗した場合も開始しません。
- ヘッダーには通知状態を `通知非対応`、`通知の許可が必要`、`通知許可済み`、`通知が拒否されています` のいずれかで表示します。
- OSの通知設定や集中モードにより通知が見えない場合でも、画面内の `Time up!` は残ります。

# デザイン仕様

- 深いネイビーをページ背景と丸みのあるタイマー筐体に使用し、アンバーを時間表示と主要操作のアクセントに使用します。
- LED表示部は暗い表示パネル、アンバーの発光表現、細かなグリッド、等幅フォントを組み合わせたレトロ機器風です。
- READYはグレー、RUNNINGは点滅するエメラルド、PAUSEDはアンバーのインジケーターで状態を区別します。
- エラーはローズ、完了はエメラルド、通知許可待ちはアンバーを使い、高コントラストで表示します。
- ページ背景は単色のネイビーを基調とし、24px間隔の控えめなドットパターンを重ねます。大きな色面の背景グラデーションは使用しません。
- 1画面・中央配置の構成で、コンテンツ幅は最大 `max-w-3xl` です。
- モバイルファーストで設計し、最小表示幅は320pxです。
  - 小さい画面ではヘッダーと入力項目を縦に配置します。
  - Tailwind CSSの `sm` ブレークポイント以上では、ヘッダーを横並びにし、タイマー名と時間設定も横方向に配置します。
- 秒表示の切り替えには140ミリ秒の短いアニメーションを付けます。`prefers-reduced-motion: reduce` の場合はこのアニメーションを無効化します。
- ボタンは角丸、立体的な影、押下時の短い移動を持つ専用スタイルです。

# 実装しないと決めたこと

- 音声通知: 今回はブラウザ通知と画面内表示に完了通知を限定したため、実装していません。
- 複数タイマー: 1件のカウントダウンを扱う仕様に限定したため、実装していません。
- タイマー履歴: 単一タイマーの現在状態だけを扱う仕様のため、実装していません。
- プリセット: 分・秒を直接入力する操作に限定したため、実装していません。
- 設定・状態の永続化: 再読み込みやタブを閉じた後は `3分00秒` に戻る仕様のため、Local Storageやデータベースへの保存は実装していません。

# 技術構成

- フレームワーク・言語
  - React 19
  - TypeScript
  - Vite
- UI・スタイリング
  - Tailwind CSS
  - shadcn/uiの `Button`、`Input`、`Label` を専用クラスでカスタマイズ
  - `lucide-react` のアイコン
- ルーティング
  - React Router
  - `/` でタイマー画面を表示し、追加のタイマー用ルートは持ちません。
- ブラウザ機能
  - Notification APIによる権限確認、権限要求、完了通知
  - `setInterval`、`Date.now()`、終了予定時刻による残り時間計算
- 主要ファイル
  - `src/pages/Index.tsx`: 入力値、確定時間、残り時間、状態、通知状態、メッセージの管理、通知権限処理、カウントダウン処理、画面全体の構成を担当します。
  - `src/components/TimerDisplay.tsx`: `MM:SS` のLED表示、READY・RUNNING・PAUSEDの状態表示を担当します。
  - `src/components/TimerControls.tsx`: 状態に応じたStart、Pause、Resume、Resetボタンの切り替えを担当します。
  - `src/globals.css`: ネイビー／アンバー中心のCSS変数、LED発光、グリッド、背景パターン、短いアニメーションを定義します。
  - `src/App.tsx`: React Routerの `/` から `Index` を表示します。
